# 开发规范 — UI 与交互

> 记录每次讨论确认的 UI/交互规则，避免重复犯错。

---

## 侧边栏

- 标题行叫 **"文件列表"**（标签树视图叫 **"标签树"**）
- 标题行高度 **h-9（36px）**，与右侧 Tab 栏顶端对齐
- 切换开关在 **活动栏（ActivityBar）**，不在侧边栏头部
- 两个视图（文件树 / 标签树）用 `display:none` 切换，保持 DOM 不卸载，折叠状态不丢失

### 文件树布局（仿 VSCode）

```
┌─────────────────────┐
│ 文件列表      [切换] │  ← h-9，与 Tab 栏对齐
├─────────────────────┤
│ ▼ 工作区名(加粗)     │  ← 根节点，默认展开
│   📁 docs           │
│   📁 src            │
│   📄 README.md      │
└─────────────────────┘
```

### 标签树布局

```
┌─────────────────────┐
│ 标签树      [🔄][切换]│  ← h-9，刷新按钮仅此视图显示
├─────────────────────┤
│ ▶ 前端              │  ← 标签节点：无图标，仅箭头+名
│   ▶ React           │
│     📄 笔记.md      │  ← 文件节点：有图标
│ ▶ 未分类            │  ← 兜底节点
└─────────────────────┘
```

- 标签节点不需要额外图标（只有展开箭头 + 标签名）
- 文件节点保留文件图标
- 初始默认全部折叠
- 右键标签节点 → 排序菜单；右键文件 → 同文件树

---

## 活动栏

- `explorer` → 文件树
- `tags` → 标签树
- 点击同一项：切换侧边栏显隐；点击不同项：切换视图并展开侧边栏

---

## 底部状态栏

- 蓝色条，高度 24px
- 左侧：工作区完整路径
- 右侧：文件数 + 当前文件名

---

## 标签系统文件

配置放 `.uvnote/tags/`：
- `index.json` — 文件→标签索引
- `schema.json` — 标签树结构（JSON）
- `tree.txt` — 标签树结构（缩进文本，可手动编辑）

双向同步关系：`tree.txt` ↔ `schema.json`。切换到标签树视图时总是从磁盘重新加载。
